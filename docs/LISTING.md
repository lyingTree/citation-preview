# Citation Preview listing copy

## Display name

Citation Preview

## Short description

Preview numeric citation groups in Page preview using the numbered bibliography in the same note.

## Long description

Citation Preview shows numeric citations such as [1], [1,3,5], and [1-10] in Obsidian Page preview. Hover over a group to read the corresponding bibliography entries in one popover.

Use bracketed numeric citations and explicitly numbered references under a supported heading in the same note. Enable the Page preview core plugin. Citation Preview assembles groups in memory without helper files or edits to the note. See the README for supported formats and compatibility.
